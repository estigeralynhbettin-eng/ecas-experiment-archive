# Archive and citation history

The dataset is published on Zenodo at https://doi.org/10.5281/zenodo.23444761 (version 1.0.0, 18 October 2026).

The original GitHub `v1.0.0` tag and release assets are preserved. They contain the same scientific records and historical evidence as the Zenodo deposit. After Zenodo assigned the real DOI, five archive files changed: CITATION.cff, README.md, VERSION_POLICY.md, MANIFEST.json and SHA256SUMS. File names, LICENSE_SCOPE.csv, scientific files and historical records did not change. This update makes citation links available on main and does not rerun experiments.

- Initial GitHub archive SHA-256: `e39167d02e86b59374dbaa488c87fdb2f08f00ba8c76dbe5b6b2bc851f1f94fa`.
- Final Zenodo archive SHA-256: `de1770844a2e5c83e75dcb4eba6ed04529f1eabd35a396dbde4566cc53e563fb`.
- Zenodo published file: https://zenodo.org/records/23444761/files/ECAS_Experiment_Archive_1.0.0.zip?download=1

These ZIP files have different documentation bytes and therefore different whole-file hashes. Use the Zenodo file when citing or reproducing the deposited version. The repository main branch includes the final citation documentation; the immutable GitHub v1.0.0 snapshot and its original assets retain their initial identity.
