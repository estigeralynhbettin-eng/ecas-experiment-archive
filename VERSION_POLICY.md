# Version policy

This is public archive version 1.0.0, dated 18 October 2026. It derives from Online Resource 3 of the A18 revised manuscript. Original experiments, later adapted-workflow comparisons, related controls, and matrix checks retain their distinct versions and scopes. Scientific failures, generated policy content, inputs, results and source records retain their byte identities.

The new public release changes release documentation and licensing only. Any new measurements must be archived separately. The original R12 archive, where supplied, remains unchanged and retains its existing terms. Historical execution receipts are not new executions of this release; current preparation performs static file and packaging checks only. The dataset version 1.0.0 does not rename the underlying revision-2 matrix items or historical experiment configurations.

The Zenodo DOI will be added only after the real identifier is assigned. See CITATION.cff and the final Zenodo record for citation metadata. No accepted-publication or manuscript-submission status is asserted by this archive.
